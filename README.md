# Soral Tech

Site institucional estático em português, feito com HTML, CSS e JavaScript.
Endereço público: https://soraltech.github.io/.

## Visualização local

Abra `index.html` no navegador ou execute `python3 -m http.server 8000` e acesse http://localhost:8000/.

## Publicação e SEO

As alterações locais precisam ser enviadas ao repositório e publicadas pelo GitHub Pages para chegar ao site público.

O site inclui título e descrição, URL canônica, dados estruturados de Organization e WebSite, metadados de compartilhamento, robots.txt e sitemap.xml.

Após publicar:

1. Adicione `https://soraltech.github.io/` como propriedade de prefixo de URL no Google Search Console e conclua a verificação com o método indicado pelo Google. Nenhum código de verificação foi adicionado, pois ele é específico da sua conta.
2. Envie `https://soraltech.github.io/sitemap.xml` em Sitemaps.
3. Inspecione a página inicial e solicite indexação.
4. Confira os dados estruturados no Rich Results Test e o desempenho móvel no PageSpeed Insights.
5. Acompanhe indexação, consultas e cliques no Search Console.

Se adotar um domínio próprio, atualize as URLs em `index.html` (canonical, Open Graph, imagem e JSON-LD), `robots.txt` e `sitemap.xml`. Cadastre o novo endereço no Search Console.

Não há endereço físico, avaliações, preços ou projetos de clientes nos dados estruturados: essas informações precisam ser reais e confirmadas antes de serem publicadas. SEO não garante uma posição específica nos resultados.
